# Support

This repository ships the **Community / Academic** edition of SWOCTS Cyber
Range, powered by OpenCyberRange. Support is best-effort by the maintainer.

## Where to ask

| Need | Where |
|---|---|
| How something works | The [user manual](Manual-Lite/index.md) first, then the relevant [repository document](docs/README.md) |
| A reproducible bug | Open a [bug report](.github/ISSUE_TEMPLATE/bug_report.md) |
| A feature or lab idea | Open a [feature or lab request](.github/ISSUE_TEMPLATE/feature_request.md) |
| A security vulnerability | Report privately, **not** in a public issue. Follow [SECURITY.md](SECURITY.md) |
| Privacy, erasure, or a data request | Follow [PRIVACY.md](PRIVACY.md) and the detailed [privacy notice](docs/PRIVACY-NOTICE.md) |
| Commercial or Enterprise licensing | See [LICENSING.md](LICENSING.md) |

## Before you post

- Search existing issues and the manual.
- Include the release (`/api/version`), commit, deployment shape, and the exact
  steps.
- Include logs or screenshots with **secrets and personal data removed**.
- Never post a real password, API key, private key, learner name, email, IP, or
  another institution's data.
- Use a synthetic reproduction for a lab issue.

## What is in scope for free support

Community / Academic guidance, reproducible defects, documentation gaps, and
lab-content corrections. Deployment-specific consulting, custom integrations,
and commercial support require a separate agreement.

## Response expectations

Security reports are acknowledged within five business days and updated within
ten. Other issues are triaged when the maintainer is available; there is no
guaranteed response time for the Community / Academic edition.
