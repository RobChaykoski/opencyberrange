Nine exercises take a learner from directory enumeration to an evidence-backed attack path and remediation plan. The directory is an LDAP simulation of Active Directory, so the labs run without a Windows domain controller.

| Exercise | Focus | Time |
|---|---|---:|
| 11.1 | Domain Enumeration and Attack-Path Mapping | 60 min |
| 11.2 | Kerberoasting | 90 min |
| 11.3 | AS-REP Roasting and Password Spray | 80 min |
| 11.4 | ACL and DACL Abuse | 110 min |
| 11.5 | Delegation Abuse | 110 min |
| 11.6 | AD CS Abuse | 110 min |
| 11.7 | Credential Dumping and Ticket Abuse | 130 min |
| 11.8 | GPO, LAPS, and Tiered Administration Defence | 90 min |
| 11.9 | Attack Path and Remediation Capstone | 160 min |

## Rules

- Use only the target and accounts shown in the exercise.
- Treat recovered credentials and tokens as evidence, not as permission to go beyond the lab.
- Do not put a token in a shared document.

> The directory is an LDAP simulation of Active Directory; Kerberos is discussed in the chapter.
