This chapter collects the linux exercises that extend the
core workbook. Each exercise is a self-contained walkthrough with a scenario,
objectives, reference commands, analysis questions, and a defensive takeaway.

Work through the exercises in order. The reference commands use `<target>` where
the lab shows you the actual address. If a command fails, read the error before
changing the technique; report a persistent platform failure to your instructor
so it is not mistaken for learning difficulty.
