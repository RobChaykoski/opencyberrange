# WEB11: Modern Application Security

Ten exercises cover the modern application-security surface: API inventory, object and function authorization, GraphQL, JWT, OAuth, CI/CD, containers, Kubernetes, supply chain, and a capstone assessment.

| Exercise | Focus | Time |
|---|---|---:|
| W11.1 | API Security Inventory | 60 min |
| W11.2 | BOLA and BFLA | 80 min |
| W11.3 | GraphQL Security | 90 min |
| W11.4 | JWT Security | 90 min |
| W11.5 | OAuth and OIDC Abuse | 100 min |
| W11.6 | CI/CD Pipeline Security | 90 min |
| W11.7 | Container Security | 90 min |
| W11.8 | Kubernetes Security | 120 min |
| W11.9 | Supply Chain and Artifact Integrity | 80 min |
| W11.10 | Modern Application Security Capstone | 160 min |

## Rules

- Use only the target and accounts shown in the exercise.
- Treat recovered credentials and tokens as evidence, not as permission to go beyond the lab.
- Do not put a token in a shared document.

> Every target is fictional and isolated. Do not test a real host.
