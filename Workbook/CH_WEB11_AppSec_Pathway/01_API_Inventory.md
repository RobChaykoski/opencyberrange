# API Security: Inventory and Attack Surface Mapping

**Track:** Web · **Level:** 11 · **Time:** 60 minutes · **Difficulty:** beginner

## Scenario

A public API ships with documentation, but an internal inventory endpoint is exposed. Enumerate the surface and recover the token.

## What you will practise

- Build an API inventory from documentation and responses
- Identify undocumented and internal endpoints
- Classify endpoints by authentication and data sensitivity
- Record the inventory as assessment evidence

## Work through the exercise

1. Open the exercise from the Web track, level 11.
2. Work from the scenario; use the lab hints only when you are stuck.
3. Recover the assessment token and write the evidence the exercise asks for.

## Evidence

- The assessment flag.
- A short note that names the weakness and the defensive control.

## Defensive takeaway

Server-side authorization, strict token validation, least-privilege runtime, and artifact verification remove this class of weakness.

> The target is a local, intentionally vulnerable API. Do not test a
> real host or another learner's session.
