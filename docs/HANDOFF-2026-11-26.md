## Operational notes

- Stop marks the session `stopping` and runs teardown in a background task. A
  new spawn can start before the old containers disappear; the network
  allocator handles it, but avoid starting a second lab in the first minute
  after a stop when possible.
- The backend host port `127.0.0.1:8000` can briefly time out while Docker
  teardown/spawn runs; the application path through nginx stays correct.
- `wiki_origin` should be `https://<host>:8443`; if someone clears platform
  settings, the TLS frontend derives the split again. Set it explicitly only
  for a different wiki hostname.
- Rollback images: `opencyberrange-backend:pre-v5.53.1`,
  `ocr-frontend:pre-v5.53.1`. Development rolls back by rebuilding `v5.53.0`.
- Production pre-deploy backup: `~/backups/ocr-backup-20261126-184145.dump`.
  Development pre-deploy backup: `~/opencyberrange/.backups/20261126_184510`.
