# Accessibility statement

Status: **Release 4 baseline. Not a signed VPAT/ACR.**

## Target

WCAG 2.2 Level AA for the learner-facing application, with WCAG 2.1 AA as the
procurement baseline used by Ontario AODA and most Canadian institutions.

## Implemented in Release 4

- Semantic landmarks and a skip link on the application shell.
- Keyboard operation for navigation, menus, dialogs, forms, and the institution
  sign-in panel.
- Visible focus indicators, including the SSO buttons and directory form.
- Labelled form controls. The LDAP directory fields now have visible labels, not
  placeholder-only labels.
- Error messages announced with `role="alert"`; the login error banner is
  focusable.
- No colour-only status; contrast checked for primary text and the SSO panel.
- `prefers-reduced-motion` handling for non-essential animation.

## Accommodations

- Each learner can have a per-student time multiplier (1.0x–3.0x) and a
  due-date extension (0–365 days), managed from **Instructor → My Courses →
  Students → Accommodations**. A per-student record replaces the operator-wide
  `session_accommodation_percent` for timed lab sessions.
- The multiplier scales lab session length and one-hour extensions. The
  extension shifts assignment due dates shown to that learner.
- Every change is written to `accommodation_events` (append-only) and the
  activity log; the notes field is for a reference, not diagnosis details.
- The learner can **pause the session clock** with a required reason. While
  paused the countdown is frozen, the scheduler does not reap the session, and
  resuming credits the paused time to the expiry. Pause/resume events are
  audited.
- There is no hard pass/fail timer in the learner path.

## Known limitations

- No external accessibility audit has been completed.
- The workbook/wiki is generated HTML; its tables and diagrams have been
  reviewed, but a full audit is pending.
- Some legacy admin screens are keyboard-usable but were not designed against
  the 2.2 target size and focus-not-obscured criteria.
- PDF exports are generated by the platform; their tagging and reading order
  have not been certified.

## VPAT / ACR

A VPAT 2.5 is a signed conformance report produced from an audit. Release 4 does
not include one. The Release 5 plan is to commission the audit, publish the ACR,
and attach remediation timelines for any partial criteria.

## Feedback

Accessibility issues should go to the institution's platform contact and be
recorded as defects. Do not describe this build as "WCAG certified".
