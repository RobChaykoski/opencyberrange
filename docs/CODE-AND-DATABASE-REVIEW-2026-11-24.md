## Fixed in this pass

| Area | Fix |
|---|---|
| Cross-worker state | Exercise-tester runs, admin impersonation state, and stress runs now use `/app/run-state` (mode 750) instead of `/tmp`. Local development falls back to a private OS temp directory. |
| WireGuard key validation | `WG_ENCRYPTION_KEY` and previous rotation keys are validated as Fernet keys at startup. |
| Topology input | `security_opt` must be a list of strings that keeps `no-new-privileges`; `http_port` rejects booleans, non-integers, and values outside 1-65535. |
| Password-breach digest | The HIBP SHA-1 lookup is marked `usedforsecurity=False`; passwords remain Argon2id. |
| Index hygiene | Migrations `0061` and `0062` drop non-unique indexes that duplicate a primary key or unique constraint, and add `ix_courses_instructor_id` and `ix_lab_sessions_lab_id`. |
| Model drift | Removed duplicate index declarations from the models so `create_all` does not recreate them. |

## Findings

| Severity | Area | Evidence | Status |
|---|---|---|---|
| High | Docker isolation | `docker_manager.py` talks to the Docker socket and runs privileged or host-network helper containers with runtime `apk add`. Backend code execution is host-root-equivalent. | Open; host-level decision and a pre-baked helper image are required. |
| High | Alembic drift | `alembic check` reports many new upgrade operations. Runtime tenant DDL adds `institution_id` columns and RLS outside migrations; restored databases also retain legacy indexes. An autogenerated migration could propose destructive drops. | Open; do **not** run `alembic revision --autogenerate` until the baseline is reconciled. Use hand-written migrations. |
| High | Admin tenant scope | Several non-platform admin actions use the platform-admin dependency without the institution filter used by the core user endpoints. | Open; audit every admin action and make platform-only actions explicit. |
| High | Login throttling | Failure counters are in-process, so multiple workers multiply the limit. | Open; move counters to Valkey or another shared store. |
| Medium | RLS gaps | `users` is the tenant root and has no RLS. `auth_sessions`, `refresh_tokens`, `rbac_user_roles`, and `service_credentials` also have no RLS; the last two carry `institution_id`. | Review before multi-tenant use; single-host `default` tenant is not exposed. |
| Medium | Host patches | Production had 21 pending packages, including Docker 29.10.0, kernel 6.8.0-151, systemd 255.4-1ubuntu8.19, and containerd 2.4.2-4. Development had 35. | Unattended security upgrades are active and installed libssh-4, python3-oauthlib, and tzdata on 24 November. Kernel, Docker, and systemd need a maintenance window and a host reboot or Docker restart. |
| Medium | Base-image pinning | `nginx:alpine` is unpinned. The current tag resolves to nginx 1.31.8, the same version already running. | Pin the digest in the next dependency wave. |
| Low | Unindexed foreign keys | 54 FKs have no index. Most are actor/creator columns on small or audit tables. `lab_sessions.lab_id` and `courses.instructor_id` were the hot paths. | Fixed for the hot paths; the rest are low-cardinality and low-volume. |
| Low | SQL f-string scanner hits | Bandit reports 12 `B608` hits in consent hooks, erasure, tenant RLS, and an export README. The SQL identifiers come from fixed tuples or pass an identifier regex; values are bound parameters. | Accepted; comments and tests document the boundary. |
| Low | URL opens | `release_check.py` opens a static GitHub URL; `rangebox.py` opens a Docker-derived container IP. | Accepted. A future defensive check can require an IP literal in the RangeBox probe. |
| Low | Lab upload chmod | Uploaded `.sh` and `.py` entrypoints are mode 0755. Extraction is size- and path-validated. | Accepted; lab containers need the entrypoint to be executable. |

## Upgrade path

No immediate major upgrade is required for the current release line.

1. **Host patch window.** Apply `apt-get upgrade` for the kernel, Docker,
   containerd, systemd, and compose packages. Reboot if `/var/run/reboot-required`
   appears. Back up first and verify `/api/version`, health, and containers.
2. **Dependency patch wave (5.42.0).** Update FastAPI, SQLAlchemy, and Pydantic
   within their minor lines, run the full backend and frontend suites, rebuild,
   and sign a new supply-chain lock.
3. **Base-image refresh.** Pin `nginx:alpine` by digest, refresh the pinned
   `python:3.13-slim` and `node:22-alpine` digests, rebuild, and scan the images.
4. **PostgreSQL 15→17.** This remains a planned major upgrade. Use a dump/restore
   or `pg_upgrade` on a maintenance window, then run the restore drill and the
   RLS role check. Do not combine it with an application feature release.
5. **Runtime majors.** Python 3.14, Node 24, and Ubuntu 26.04 are future waves.
   Keep the current supported stack until each wave has its own test plan.

## Residual risk

The Docker socket and privileged helper containers remain the highest-risk item.
They are a host-isolation decision, not a code-style cleanup. The next security
work should either pre-bake the helper image and remove runtime package
installation, or move the helper to a host-side agent with a narrow API.
