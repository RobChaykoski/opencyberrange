## Security evidence

- Authorization matrix covers unauthenticated, student, instructor,
  outsider-instructor, and admin surfaces.
- Input safety rejects NUL, C0/C1 controls, bidi overrides, zero-width
  spoofing, unpaired surrogates, noncharacters, and dangerous line breaks while
  accepting kanji, Arabic, Devanagari, accented Latin, and emoji in display
  text.
- CSV/Excel exports neutralise formula-like values, including
  `=HYPERLINK(...)`, `@SUM(1+1)`, and `+cmd|' /C calc'!A0`.
- No lab compose file uses `privileged`, the Docker socket, host networking,
  `SYS_ADMIN`, devices, or a writable host bind mount.
- The ten High capability findings are `NET_ADMIN`/`NET_RAW`/`SYS_NICE` in
  sensor and firewall labs; they are justified by the lab function and remain
  on the per-learner lab network.
- Residual risk: lab networks are normal Docker bridges, so outbound internet
  egress is not default-deny. This is accepted explicitly in
  `docs/decisions/0005-lab-network-egress.md`; per-lab allowlisting is deferred.
- OCI image labels now carry title, description, version, revision, source, and
  licence.

## Lab validation evidence

`validate-lab.py --all` reports **149 labs, 0 errors, 0 warnings**. That proves
structure, metadata, flags, test steps, compose configuration, and password
safety. It does **not** prove a learner can complete the lab.

The twelve instructor-led assessments carry explicit workbook and hint
exemptions. The static evidence is complete; a live student walkthrough of the
lab set is still the human gate.

## Accessibility evidence

Automated axe/WCAG 2.2 AA checks were run with Microsoft Edge against the
development deployment:

- student `/dashboard` (individual radar) at `1280×900` and `320×800`;
- instructor `/courses/10?tab=analytics` (cohort radar) at `1280×900` and
  `320×800`;
- instructor `/reports` at `1280×900` and `320×800`.

Result: **0 axe violations** on every route and viewport. Both radar charts
expose a `role="img"` text alternative and a screen-reader table with one row
per axis. At 200% text, both radar routes reflow without page-level horizontal
overflow. The Reports data tables scroll horizontally at 200% text; WCAG 1.4.10
permits two-dimensional scrolling for data tables.

Fixes made during the audit:

- skill-matrix partial cells now use the amber badge text token instead of the
  lower-contrast warning token;
- analytics RAG badges use the badge text tokens;
- the screen-reader competency table is wrapped so it no longer contributes to
  document width;
- activity and analytics table regions are keyboard-focusable.

Still open:

- PDFs carry metadata and a language tag but are **not** fully tagged PDF/UA.
  The accessible HTML surface remains the primary accessible format.
- The `/reports` data-table horizontal scroll at 200% text is accepted for
  two-dimensional data, not removed.
