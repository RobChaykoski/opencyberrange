## Scope

2.5.4 is a patch release focused on:

- machine-readable lab metadata;
- measurable learning outcomes;
- MITRE ATT&CK alignment;
- instructor learning analytics;
- dashboard clarity for admins, instructors, and students;
- security, reliability, and database performance fixes shipped after 2.5.3.

## Analytics and dashboards

- Instructor **Teaching focus**: near-certificate learners, inactive 7+ days,
  recent wins.
- Instructor learning snapshot: **Students Active**, **Labs Completed**,
  **Average Score**, **Struggling Students** over seven days.
- Student course cards: per-course completion progress and workspace summary.
- Basic learning analytics contract: lab started, lab completed, completion
  time, pass/fail, retry count.
- MITRE ATT&CK panel in the learner exercise brief.

## Known limitations

- 2.5.4 is signed with the rotated release key
  `095B D8B5 6802 771D A27E 759E 1BAE 4CD3 1609 A1BF`.
  The private key is held outside the repository by the release owner.
- CTFd is a separate application on `.41`; 2.5.4 does not change CTFd.
- The public `ocr.swocts.com` NPM upstream points at `.44`.
- Per-exercise instruction-clarity ratings are still course-level only.
- Step-level abandonment events are not collected; exercise health reports that
  limitation explicitly.
- Aggressive pruning of prebuilt lab images was intentionally not performed to
  avoid breaking lab spawns.
