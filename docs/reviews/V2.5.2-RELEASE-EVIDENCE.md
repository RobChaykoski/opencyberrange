## Security evidence

- Authorization matrix covers unauthenticated, student, instructor,
  outsider-instructor, and admin surfaces.
- Input safety rejects NUL, C0/C1 controls, bidi overrides, zero-width
  spoofing, unpaired surrogates, noncharacters, and dangerous line breaks while
  accepting kanji, Arabic, Devanagari, accented Latin, and emoji in display
  text.
- CSV/Excel exports neutralise formula-like values, including
  `=HYPERLINK(...)`, `@SUM(1+1)`, and `+cmd|' /C calc'!A0`.
- No lab compose file uses `privileged`, the Docker socket, host networking,
  `SYS_ADMIN`, devices, or a writable host bind mount.
- The four High capability findings are `NET_ADMIN`/`NET_RAW`/`SYS_NICE` in
  sensor and firewall labs; they are justified by the lab function and remain
  on the per-learner lab network.
- Residual risk: lab networks are normal Docker bridges, so outbound internet
  egress is not default-deny. This is recorded as a release decision, not
  silently accepted.

## Lab validation evidence

`validate-lab.py --all` reports **149 labs, 0 errors, 0 warnings**. That proves
structure, metadata, flags, test steps, compose configuration, and password
safety. It does **not** prove a learner can complete the lab.

`lab-release-proof.py` is the stricter gate. Current result:

- **0 pass**
- **120 review**
- **29 fail**

Reasons:

- **29 labs have no linked workbook** and fail the workbook/environment match.
- **149 labs are marked review for learner-evidence-based difficulty**. The
  platform does not yet store the learner evidence needed to justify difficulty.
- 9 assessments are correctly marked review rather than fail because they are
  instructor-led.

This is the main release blocker. The feature set is ahead of the validation
evidence.

## Accessibility evidence

Automated axe/WCAG 2.2 AA checks were run with Microsoft Edge against the
development deployment:

- `/login`, `/register`
- `/dashboard`, `/reports`, `/admin`, `/admin?tab=settings`, `/profile`,
  `/about`, `/privacy`, `/exercises`, `/courses`, `/rangebox`, `/events`
- Desktop `1280×900` and reflow `320×800`
- Keyboard focus, visible focus, form labels, select names, colour contrast,
  chart text alternatives, and 24px target size

Result after fixes: **0 axe violations across all audited routes and
viewports**. 320px reflow has no page-level horizontal overflow.

Still open:

- At **200% text**, the Reports skill table and the Admin users table scroll
  horizontally inside their regions. This is allowed for data tables, but the
  page still reports a synthetic document overflow in the audit; confirm with a
  real browser zoom test before claiming full 1.4.4 coverage.
- PDF accessibility for certificates and transcripts is **not verified**. The
  generated PDFs have no tagged-structure or PDF/UA evidence.
- Timed-exercise accommodation is **not evidenced**. Session extension exists,
  but there is no documented accommodation profile or test.

## Release decision

**Do not call v2.5.2 fully release-ready yet.** The security, runtime, upgrade,
analytics, and link evidence is strong. The release is blocked by:

1. 29 labs without a workbook.
2. 149 labs without recorded learner-evidence-based difficulty.
3. Production lab prebuild coverage (19 of 149).
4. PDF accessibility and timed-exercise accommodation evidence.
5. The 200% text table-scroll confirmation.
6. Default-deny lab egress decision.

The next release should close these before adding new features.
