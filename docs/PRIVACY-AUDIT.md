# Privacy exclusion audit

Generated by `python scripts/audit-privacy-exclusions.py --report docs/PRIVACY-AUDIT.md`.
Do not edit by hand. Regenerate after changing an analytics query.

## Scope

Learner-data models: `ExercisePulseSurvey`, `ExerciseReaction`, `SurveyResponse`.

An instructor-facing route passes when its query is narrowed by `is_minor`/`minor_ids`/`user_ids`, or is scoped to `current_user.id`. A call to a helper passes when it passes a filtered `user_ids` set, or when the helper has no such parameter and the route is self-scoped.

## Result

No findings. Every instructor-facing analytics query for a learner-data model is narrowed to non-minor accounts.

## Limits

This is a static invariant check, not a proof. It recognises the helpers and guard names this codebase uses. A new query path, a new guard name, or a query built through metaprogramming will not be seen, so a clean report is evidence for review, not a certificate.
