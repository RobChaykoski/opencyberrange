ICS / OT / SCADA PCAP Challenges
Built around Pcapper. Every challenge is designed to be worked with Pcapper — a modular PCAP forensics tool with dedicated ICS/OT analyzers (Modbus, DNP3, IEC-104, S7, EtherNet/IP & CIP, IEC 61850 MMS/GOOSE/SV, BACnet, OPC UA, PROFINET, TriStation…). Every challenge has two complete walkthroughs: the Pcapper track (default) and a tshark / Wireshark track — switch with the toggle on each challenge. Openly licensed captures are mirrored in this repo's data-v1 release, and every challenge shows the command and download links for its own captures (all datasets: DATASETS.md); python3 scripts/fetch.py --starter gets you going (mirror first, original sources for the rest).
git clone https://github.com/SackOfHacks/pcapper && (cd pcapper && pip install .)
git clone https://github.com/SackOfHacks/ICS-PCAP-Challenges && cd ICS-PCAP-Challenges
python3 scripts/fetch.py --starter && python3 scripts/build.py
pcapper data/modbus-labs-solymx/lab01_baseline.pcap --overview
