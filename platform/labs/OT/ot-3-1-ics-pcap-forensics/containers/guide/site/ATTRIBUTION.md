# Dataset attribution & licenses

The packet captures are not in this repository's git history. Datasets whose licence (or authors) allow redistribution are **mirrored, unmodified, as assets of the `data-v1` release** under their own licences; every other dataset is downloaded by `scripts/fetch.py` from its original source. **If you use these captures, cite the original authors below** — for the Creative Commons datasets this is a licence requirement, not just a courtesy.
