# Icon attribution

Most icons in this directory are original OpenCyberRange artwork: code-drawn
SVG paths using `currentColor`, created for this project.

Some paths are adapted from third-party icon sets:

| File | Source | Licence |
|---|---|---|
| `LockIcon.vue` | [Lucide](https://lucide.dev/) `lock` | ISC |
| `ShieldCheckIcon.vue` | [Feather](https://feathericons.com/) `shield` + check | MIT |

Licence texts:

- `THIRD_PARTY_LICENSES/lucide-ISC.txt`
- `THIRD_PARTY_LICENSES/feather-MIT.txt`

If you add another adapted icon, record its source and licence here and keep
the corresponding licence text in `THIRD_PARTY_LICENSES/`.
