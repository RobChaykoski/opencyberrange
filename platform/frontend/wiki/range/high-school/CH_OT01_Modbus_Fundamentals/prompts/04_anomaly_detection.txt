# OT01-L4: Modbus Anomaly Detection — Prompt Questions (Planned)

## Baseline Metrics
1. What baseline metrics would you track for Modbus traffic in a typical water treatment facility?
   - Register access frequency per PLC
   - Common function code distribution
   - Time-of-day access patterns
   - Inter-PLC communication patterns
2. How would you establish a "normal" baseline without disrupting ongoing operations?

## Anomaly Classification
1. Your alerts trigger on: "PLC-07 suddenly reads holding register 420 twice per minute during off-hours." What are three possible explanations (legitimate vs. malicious)?
2. Your alerts trigger on: "Function code 0x0F (Write Multiple Registers) used on a PLC that only supports 0x06 (Write Single Register)." What does this indicate?
3. Your alerts trigger on: "Unit ID 0 (broadcast) used with function code 0x06 (Write Single Register)." What violation does this represent?

## Detection Engineering
1. Write a sigma rule (or equivalent) for detecting after-hours Modbus register writes to safety-critical registers.
2. How would you reduce false positives while maintaining detection of genuine malicious activity?
3. What correlation rules would you add if you also monitored DNP3 or IEC 60870-5 traffic?

## Response Playbook
1. If an alert fires for unusual Modbus activity, what are the first three containment steps?
2. How would you communicate a potential OT security incident to plant operations without causing unnecessary panic?
3. What post-incident analysis would you perform to determine root cause and prevent recurrence?

## Defensive Takeaways
1. Recommend three sigma rule detections for a typical Modbus deployment.
2. Describe how a "golden image" comparison of Modbus server responses could detect compromise.
3. What tabletop exercise scenarios would you recommend for OT security teams?

## Extension: Machine Learning for OT
1. What features would you feed into an anomaly detection model for Modbus traffic?
2. How would you label training data (normal vs. attack) without real attack examples?
3. What are the risks of over-relying on ML models for OT security decision-making?
